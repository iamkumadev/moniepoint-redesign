# Moniepoint Dashboard — Redesign

A front-end redesign of the Moniepoint fintech dashboard, built as a front-end course exercise. The project recreates the mobile app UI closely while also delivering a genuine desktop/web layout — not just a stretched phone screen.

**Live demo:** _add your Vercel URL here after deploying_

## Overview

This is a static, multi-page front-end project — no framework, no build step, no bundler. Everything runs directly in the browser off Tailwind CSS (via CDN), the Lucide icon library, and vanilla JavaScript.

Pages included:

- **`index.html`** — Home dashboard: account balance, quick actions, services grid, rewards, recent transactions, and spending trends.
- **`services.html`** — "All services" directory with category sections, a live search filter, and quick-jump category chips.

Shared across both pages:

- A responsive shell — fixed sidebar navigation on desktop, bottom tab bar on mobile.
- A **dark/light theme toggle** (sun/moon icon, top right) that persists across pages via `localStorage`.
- Three **offcanvas panels** — Profile, Help & Support, and Notifications — all sharing one animated slide-in system, opened from the avatar, headphones, and bell icons.

## Features

- 📱 **Mobile-first, closely matches the source app's mobile UI** — balance card, services grid, transactions, bottom nav.
- 🖥️ **Real desktop layout** — sidebar navigation, multi-column dashboard, wider service grids — not a naive scale-up of the mobile view.
- 🌗 **Dark / light theme toggle** — CSS-variable-driven theming, no page reload, persisted across sessions and pages.
- 🔍 **Searchable services directory** — live filtering by keyword, with section auto-hide and a "no results" state.
- 👤 **Offcanvas profile panel** — account summary, level progress, quick actions, and settings links.
- 🎧 **Help & Support panel** — chat, call, email, support portal, and social links.
- 🔔 **Notifications panel** — empty state matching the source app.
- ♿ **Accessibility basics** — proper `aria-*` attributes on interactive controls, focus management on panel open/close, keyboard support (`Escape` to close, arrow-key navigation in menus), visible focus rings, `prefers-reduced-motion` support.
- 🎨 **Icon library:** [Lucide](https://lucide.dev) — no hand-coded SVGs, no icon font.

## Getting started

Since this is a static project, there's nothing to install or build.

**Option 1 — Open directly**
Just open `index.html` in a browser.

**Option 2 — Local server (recommended, avoids any file:// quirks)**
```bash
# Python
python3 -m http.server 5500

# or Node
npx serve .
```
Then visit `http://localhost:5500`.

## Design notes

- Colors are defined as CSS custom properties (`--color-base`, `--color-panel`, `--color-gold`, etc.) and mapped into Tailwind's config using the `rgb(var(--x) / <alpha-value>)` pattern — this is what allows the dark/light theme to switch instantly without regenerating any Tailwind classes, while still supporting opacity modifiers like `bg-coral/10`.
- The "All services" page renders its sections and tiles from a single JavaScript data array, rather than hand-written repeated markup — makes it trivial to add/remove/reorder services.
- Icon choices for a few items (Betting, Association, Health, Network, and the social links) are close semantic substitutes rather than 1:1 matches, since the source app's exact icon set/brand marks aren't available in Lucide.
